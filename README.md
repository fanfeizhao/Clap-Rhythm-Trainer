# ClapRhythm

ClapRhythm is a free browser-based rhythm reading and clapping trainer.

Users can create rhythms with notes, rests, triplets, dotted notes, ties, and custom time signatures. The app can play the rhythm with a metronome, record clapping through the microphone, and give timing feedback.

## Features

- Create up to 12 measures
- Custom time signatures
- Notes, rests, dotted notes, triplets, and ties
- Adjustable BPM
- Optional metronome
- One-measure count-in
- Microphone clap detection
- Early, late, missed, and extra-clap feedback
- Custom note and metronome sounds
- Horizontal or four-measures-per-row layout
